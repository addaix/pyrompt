# pyrompt.cli

Command-line interface for pyrompt.

Simple CLI for managing prompt collections.

### Functions

| [`cmd_add`](#pyrompt.cli.cmd_add)(args)     | Add a prompt to a collection.    |
|--------------------------------------------------------------------|----------------------------------|
| [`cmd_engines`](#pyrompt.cli.cmd_engines)(args) | List available template engines. |
| [`cmd_list`](#pyrompt.cli.cmd_list)(args)    | List prompts in a collection.    |
| [`cmd_new`](#pyrompt.cli.cmd_new)(args)     | Create a new collection.         |
| [`cmd_render`](#pyrompt.cli.cmd_render)(args)  | Render a template.               |
| [`cmd_show`](#pyrompt.cli.cmd_show)(args)    | Show a specific prompt.          |
| [`cmd_stats`](#pyrompt.cli.cmd_stats)(args)   | Show collection statistics.      |
| [`main`](#pyrompt.cli.main)()            | Main CLI entry point.            |
