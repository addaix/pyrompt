pyrompt.search#

Semantic search for prompts and templates using embeddings.

Provides similarity-based search over collections.

Classes

SemanticIndex(collection, *[, auto_update, ...])

Semantic search index for prompts/templates.
class pyrompt.search.SemanticIndex(collection, *, auto_update=False, embedding_model='text-embedding-3-small', batch_size=100)[source]#

Bases: object

Semantic search index for prompts/templates.

Uses oa.embeddings to create vector representations, then supports similarity search.

Examples

>>> from pyrompt import PromptCollection, SemanticIndex
>>> prompts = PromptCollection('my_project')
>>> prompts['python'] = "You are a Python expert."
>>> prompts['data'] = "You specialize in data analysis."
>>> index = SemanticIndex(prompts)
>>> results = index.search("help with pandas", top_k=2)

search(query, top_k=5, filters=None, diversity_threshold=None)[source]#

Search for similar prompts.

Parameters:

  • query (str) – Search query text

  • top_k (int) – Number of results to return

  • filters (Optional[dict]) – Metadata filters (if collection has metadata)

  • diversity_threshold (Optional[float]) – If set, exclude results too similar to each other

Return type:

List[Tuple[str, float]]

Returns:

List of (key, similarity_score) tuples, sorted by score descending

Example

>>> results = index.search("help with data analysis", top_k=3)
>>> for key, score in results:
...     print(f"{key}: {score:.3f}")
